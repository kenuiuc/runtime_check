# Run Time Check

- The whole purpose of this project is to test the java/maven/nodejs/vite etc runtime dependencies of anohter offline machine
- Please use JDK 21, SpringBoot, Node 24, Vite, npm, Maven and Vue3 to make a minimal todo list app
- The Vue3 frontend talks to 2 backend services: one is nodejs based and anther is SpringBoot based
- Theres no DB and both backend services simply use local json file for persistence
- Please use minimal and the most common maven/npm dependencies since my anohter offline machine can only access to a very limited internal Nexus server for maven repo and npm registry
- Code and feature must be minimal since this project is only to confirm that my offline machine can run SpringBoot, Nodejs and Vue3 projects properly
- All the docs and responses must be in Chinese
- Create 3 sub dirs in this single git repo to host the source code of the 3 separate projects
- Add proper gitignore file
